# Daily Workout Planner

Single-user, mobile-first workout planner: pick a body part, get a randomized routine, log sets (with weights where needed), run an interval timer, and sync history via Excel.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- date-fns, lucide-react, sonner, SheetJS (xlsx)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

Data lives in `localStorage` under `daily-workout-planner-v2`.
